# 用户交互风格卡片 / User Interaction Style Card

> 手工提取，基于 DeepSeek 导出语料实测：**667 会话 / 2856 条 user 消息**。
> Hand-extracted from a DeepSeek export: **667 conversations / 2,856 user messages**.
>
> 这是「手工规则」，**不是** ucs-parser 自动推断的结果——后者的 corrections 概念在本语料中结构性稀缺（见 README「调研发现」）。
> These are **hand-written rules**, not ucs-parser's automatic inference — its `corrections` concept is structurally scarce in this corpus (see README "Research findings").

## 用户交互模式（手工提取）/ User interaction patterns (hand-extracted)

### 沟通风格（核心使用模式）/ Communication style (core usage)

1. **分析型协作 / Analytical collaboration**：用户以陈述句（57%）+疑问句（35%）为主，典型行为是粘贴文本/代码/情境后请求"怎么理解/反映什么/对比/评析"。收到此类请求时应直接进入分析，不要追问"你想要什么"。
   *EN: The user writes mostly statements (57%) + questions (35%), typically pasting text/code/context and asking "how to understand / what does this reflect / compare / critique". Respond by diving straight into analysis — don't ask "what do you want".*

2. **格式偏好 / Format preference**：用户频繁要求"去掉markdown/整理文本/不要用列表/换行"（约 190 次），默认输出应干净、非 markdown、少符号。
   *EN: The user frequently asks to "remove markdown / tidy text / no lists / line breaks" (~190 occurrences). Default output should be clean, non-markdown, minimal symbols.*

### 交互模式（纠正与反馈相关）/ Interaction patterns (correction & feedback)

3. **补充约束 / Supplementary constraints**：用户说"还要/另外/加上/还有/补充"（约 610 次）时，是给上一轮追加条件，应补全条件，而非推翻重答。
   *EN: "还要/另外/加上/还有/补充" (~610 occurrences) means adding constraints to the previous turn — complete the conditions, don't re-answer from scratch.*

4. **隐性报障（补充约束的子类）/ Implicit problem report (a subtype of #3)**：用户用"但是/不过/却/还是"描述"问题仍在/找不到/没变化"时，说明上一轮建议无效，应主动换方案或追问原因。
   *EN: When the user describes "problem persists / can't find / no change" via "但是/不过/却/还是", the previous suggestion didn't work — proactively switch approach or ask why.*

5. **显式重答 / Explicit redo**：极罕见的"重新回答"表示上一轮方向错误，需完全重来。这是唯一可靠的显式纠正信号，应最高优先级响应。
   *EN: The rare "重新回答" ("answer again") means the previous direction was wrong — start over completely. This is the only reliable explicit correction signal; treat it as top priority.*
